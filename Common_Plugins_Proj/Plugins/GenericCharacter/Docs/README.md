'Generic Character' is a base Character C++ class that contains logic for a handful of common movement capabilities, ready to hook up to input events.
Current capabilities:
- Walking
- Look
- Jumping
- Crouching
- Sprinting
- Sliding

Within this plugin there are also a few template blueprints for; 1st person, 3rd person, side-scroller/2D and top-down characters. Each one is an example of how minimal setup is required to achieve any character configuration, or to serve as a base blueprint from which to extend from. 
For each of these template characters there exists a playground map to test capabilities in a somewhat 'real scenario'.
